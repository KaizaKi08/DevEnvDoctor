# DevEnv Doctor v0.1.0

**Source-only Release**

DevEnv Doctor is a local Windows desktop diagnostic tool. It checks PATH, discovers Python, Git, Node.js, npm, and Codex CLI, and verifies versions for trusted Python, Git, and Node.js executables. The Codex configuration check uses metadata from the default local configuration path.

Download the v0.1.0 source archive and follow the [installation guide](https://github.com/KaizaKi08/DevEnvDoctor/blob/v0.1.0/docs/installation.md). Install PySide6, Qt runtime dependencies, Shiboken and Pydantic through PyPI as described in the guide.

JSON and HTML file export is disabled. Scans run locally. See the [privacy and security notes](https://github.com/KaizaKi08/DevEnvDoctor/blob/v0.1.0/docs/security.md).
